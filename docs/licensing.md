# the licences

im using **MIT for code** and **CC BY 4.0 for original documentation, hardware
plans and the invented sample dataset**.

MIT is a short permissive software licence, which makes it straightforward
for someone to reuse the learning code while keeping the licence notice.
CC BY 4.0 fits notes, diagrams and plans: others can share and adapt them,
with attribution and changes stated. both permit commercial reuse.

| material | licence |
| --- | --- |
| Python source, package files and future original firmware/Pi source | [MIT](../LICENSE) |
| original Markdown docs, root README, context and changelog | [CC BY 4.0](../LICENSE-DOCS) |
| original hardware plans and diagrams | [CC BY 4.0](../LICENSE-DOCS) |
| wholly simulated example files in `data/sample/` | [CC BY 4.0](../LICENSE-DOCS) |
| linked manufacturer docs and other third-party material | their own terms |

there is no real garden dataset here. a licence for the invented example
does not give permission to publish private future photographs, locations
or personal records. those need their own consent and sharing decision.

licensing a plan does not establish that the hardware works or grant rights
to third-party patents or trademarks. the project is still a simulation.

references: [MIT licence](https://opensource.org/license/mit),
[CC BY 4.0 summary](https://creativecommons.org/licenses/by/4.0/),
and [CC BY 4.0 legal code](https://creativecommons.org/licenses/by/4.0/legalcode.en).

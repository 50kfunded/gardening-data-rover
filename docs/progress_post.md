# a progress post

ive got the first software stage of my gardening data rover working on my laptop. it creates a run folder with CSV readings and metadata, then checks 300 simulated samples over 30 virtual seconds. ive organised the code into the simulation, shared data format, analysis and planned hardware sections, with a labelled example dataset and a list of build milestones. all the readings are invented. no hardware has been built yet, and there isnt an AI model or real dataset. the next stage is getting the parts and testing the Pi, motors, encoders, sensors and camera one milestone at a time.

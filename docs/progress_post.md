# A progress post

I've got the first software stage of my gardening data rover working on my PC. It creates a run folder with CSV readings and metadata, then checks 300 simulated samples over 30 virtual seconds. I've organised the code into the simulation, shared data format, analysis and planned hardware sections, with a labelled example dataset and a list of build milestones. All the readings are invented. No hardware has been built yet, and there isn't an AI model or real dataset. The next stage is getting the parts and testing the Pi, motors, encoders, sensors and camera one milestone at a time.

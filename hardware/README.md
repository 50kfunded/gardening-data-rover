# Planned hardware

No hardware has been built or tested yet. These files describe the proposed
prototype from the brief; they are not an as-built wiring record.

- [Parts and approximate allowances](parts.md)
- [Pin-by-pin wiring and planned mounting](wiring.md)

We will check the actual modules before wiring, then record changes and test
results one milestone at a time. Counter firmware and serial code are prepared,
but only computer checks have run. All hardware work is untested.
